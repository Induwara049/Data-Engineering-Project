<h1> Data Engineering Project </h1>
<h2>The Data Engineering coursework  in 2nd year</h2>
The task was to find an optimal dataset that can used for a statistical analysis and design a data pipeline for that scenario. For this specific task I have used Google Cloud Platform(GCP) since there were hardware issues with Hadoop. The data I chose for this is taken from Kaggle and it is about a Car Stock in America from 2016 to 2021.
